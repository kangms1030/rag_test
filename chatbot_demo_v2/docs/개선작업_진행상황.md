## 작업 8을 마무리하려면

재색인은 **원자적 교체**다. 기존 `ragdata/index` 는 한 번도 덮어쓰지 않는다.

```bat
:: 1) 빌드 (완료됐으면 건너뜀) — ragdata/index_new 에 생성
python -X utf8 chatbot_demo_v2\scripts\reindex.py

:: 2) 새 색인으로 평가 — RAGDATA_DIR 은 그대로 두고 index_new 를 index 로 임시 교체하거나
::    reindex.py --promote 후 평가 → 악화 시 --rollback
python -X utf8 chatbot_demo_v2\scripts\reindex.py --promote
python -X utf8 chatbot_demo_v2\scripts\run_eval.py --tag reindex --no-cache
python -X utf8 chatbot_demo_v2\scripts\ab_compare.py final reindex

:: 3) 악화 문항이 있으면 즉시 되돌린다
python -X utf8 chatbot_demo_v2\scripts\reindex.py --rollback
```

**판단 기준**: `ab_compare` 의 "라우트 악화 N문항"이 0이고 근거 정밀도가 떨어지지 않을 것.
위생 필터가 정상 청크를 잘못 지울 수 있으므로 반드시 확인한 뒤 유지한다.
