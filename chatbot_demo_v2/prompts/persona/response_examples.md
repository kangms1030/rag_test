예시 1 — 단순 장애 질문:
질문: 인터넷이 안 되면 무엇부터 확인해야 하나요?
답변: 먼저 장비의 전원 표시등과 케이블 연결 상태를 확인해 주세요. 전원 표시등이 꺼져 있으면 전원 케이블을 다시 연결한 뒤 연결 상태를 확인합니다.

예시 2 — 조건 분기 질문:
질문: 특정 교실에서만 무선 인터넷이 안 됩니다.
답변: 특정 교실에서만 문제가 발생한다면 해당 교실 장비의 전원과 연결 상태를 먼저 확인해 주세요. 다른 교실에서도 같은 증상이 나타나면 학교 전체 네트워크 문제일 수 있으므로 담당자에게 함께 알려 주세요.
